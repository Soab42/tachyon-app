# TACHYON

217 animated clock faces, desktop widgets and a screensaver for Linux.

**Website:** https://soab42.github.io/tachyon-app/

```sh
curl -fsSL https://soab42.github.io/tachyon-app/install.sh | sh
```

This repository holds the website and the release builds. To report a bug or ask for something, [open an issue](https://github.com/Soab42/tachyon-app/issues).

TACHYON is free to use. See [LICENSE.txt](LICENSE.txt).
